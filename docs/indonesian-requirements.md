# Ayo Bicara!（インドネシア語会話） 要件定義書

デモ版（v0）の要件。ヒアリング（一問一答）の結果と、それを受けた設計判断を記録したもの。
かなフラッシュと同じリポジトリの別ページ（`/indonesian`）として動く。

## 1. 目的とスコープ

| 項目 | 内容 |
| --- | --- |
| 何のアプリか | インドネシア語の会話を場面ごとに練習する学習アプリ |
| 想定ユーザー | インドネシア語がまったく初めての日本語話者 |
| 今回の位置づけ | デモアプリ。通信なし・ログインなし・費用ゼロで単体で動くこと |
| 段階 | v0 は場面別の会話例。AI との自由会話は次の段階（§6）で追加する |

## 2. 学習の仕組み

| 項目 | 決定内容 |
| --- | --- |
| 収録 | 6場面（あいさつ / じこしょうかい / かいもの / レストラン / みちをたずねる / ホテル）、各6〜7セリフ |
| 1セリフの情報 | インドネシア語 ＋ カタカナ読み（目安） ＋ 日本語訳 |
| 場面ごとの語彙 | 6〜7語の「この場面のことば」 |
| 音声 | ブラウザ内蔵の読み上げ（Web Speech API, `id-ID`）。通常 / ゆっくり を切替 |
| モード1: 会話を見る | 全セリフを吹き出しで表示。読み・訳の表示切替、1文ずつ / とおしで再生 |
| モード2: ロールプレイ | 役を選ぶ → 相手のセリフは自動で表示・再生 → 自分の番は日本語の意味に合う文を3択で選ぶ |
| まちがえたとき | その選択肢を打ち消し線で無効化し、正解するまで選び直す |
| 終了時 | 1回で正解した数、まちがえたセリフの一覧、「もう一回」「役を交代」 |

## 3. 画面

### 3.1 場面の一覧
- 場面カード（絵文字・日本語名・インドネシア語名・説明）
- 端末にインドネシア語の音声がない / 読み上げ非対応の場合は注意書きを出す

### 3.2 場面
- 「場面をえらぶ」で一覧へ戻る
- タブ「会話を見る」「ロールプレイ」（切り替えると読み上げは止まる）

## 4. デザイン方針

- かなフラッシュと同じ基盤（丸ゴシック、大きな角丸、OS のダークモードに追従）
- 場面ごとに色を割り当て、ヘッダー・相手の吹き出し・進捗バーで共有する
- 自分（A / 選んだ役）は右、相手は左の吹き出し
- インドネシア語の文には `lang="id"` を付け、読み上げソフトが正しく読めるようにする

## 5. 技術要件と制約

| 項目 | 内容 |
| --- | --- |
| フレームワーク | Next.js（App Router）+ TypeScript、shadcn/ui + Tailwind CSS v4 |
| 通信 | なし。会話データは `src/lib/indonesian/scenes.ts` に同梱 |
| 音声の制約 | 音声の有無・品質は端末依存。インドネシア語の声がない端末では別言語の声になるか無音になる |
| カタカナ読み | 発音の目安。あいまい母音 e（selamat の se など）は「ゥ」系、語末の k / t は「ッ」で表記 |
| 内容の確認 | 会話文・訳はネイティブ話者または語学担当によるチェックを本番公開前に行う |

## 6. 次の段階（AI との自由会話）の想定

v0 では実装しない。追加時に判断が必要な点を先に整理しておく。

| 論点 | 想定 |
| --- | --- |
| 構成 | Route Handler（`src/app/api/...`）経由で Claude API を呼ぶ。API キーはサーバー側の環境変数に置き、ブラウザには出さない |
| 画面 | 場面タブに3つ目のモードを足す。吹き出し（`ChatBubble`）と読み上げ（`useIndonesianSpeech`）は流用できる |
| 場面設定 | 既存の場面データ（役名・語彙）をシステムプロンプトに渡し、初心者向けの短い文で返させる |
| 運用 | 従量課金になるため、利用者の範囲・1日の上限回数・費用の上限を事前に決める |
| 安全 | 入力内容の取り扱い（個人情報を入れない旨の注意書き）、不適切な応答への対処方針 |
| 静的配信との関係 | v0 は静的ページだが、AI 会話はサーバー処理が要る。Vercel ならそのまま動く |
