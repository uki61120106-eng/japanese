# 社労士 毎日30分 要件定義書（v0）

社会保険労務士試験の学習アプリ。`/sharoushi` で動く。
「毎日30分・1年で合格」を前提に、v0 で決めたことと、決めていないことを記録する。

## 1. 目的とスコープ

| 項目 | 内容 |
| --- | --- |
| 何のアプリか | 社労士試験（択一式）の一問一答・復習・模試を毎日30分で回すアプリ |
| 想定ユーザー | 働きながら1年で合格を目指す初学者〜中級者 |
| 今回の位置づけ | 自分用（公開しない）。問題は260問を収録（目標約2,000問。§5 参照） |
| 通信 | なし。学習記録はブラウザの localStorage に保存（端末間の同期はしない） |

## 2. 学習の仕組み

### 2.1 毎日のメニュー（「今日」タブ）
- 復習（期日が来た問題、上限15問）＋ 新しい問題（1日10問）
- 1問あたり約1.2分（問題文と解説を読む時間込み）で、25問 ≒ 30分に収まる量
- 回答形式は一問一答（「正しい」「誤り」）。回答直後に正誤・解説・根拠条文を出す
- 学習時間は問題ごとに計測（放置対策で1問5分を上限）。目標時間との差を表示

### 2.2 振り返り（「振り返り」タブ）
- 間隔反復（ライトナー方式）。正解するたびに次回が 1→3→7→14→30→60 日後に延びる
- 間違えたら最初の段階に戻り、翌日に再出題
- 「期日の来た復習」「前回間違えた問題」「苦手な問題（誤答回数順）」をそれぞれ解ける
- 直近4週間の学習カレンダー、科目別の着手数・定着数・正答率

### 2.3 模試（「模試」タブ）
- 本試験の択一式7科目区分から各2問、計14問。5つの記述から誤りを1つ選ぶ形式
- 一問一答の問題を5つ束ねて自動生成するため、毎回組み合わせが変わる
- 制限時間は1問3分（本試験の70問210分と同じ配分）。時間切れで自動提出
- 合否の目安: 総得点70%以上、かつ各区分40%以上
- 間違えた設問の記述は復習に自動で回る

### 2.4 年間計画（「計画」タブ）
学習開始日〜試験前日を3期に分ける。

| 期 | 期間 | やること |
| --- | --- | --- |
| インプット期 | 残りの期間（約6か月） | 科目を1つずつ、条文量に応じた日数で。重点科目の新問を優先して出す |
| アウトプット期 | 約12週間（全体の25%まで） | 全科目を横断して未着手・苦手な問題を演習 |
| 直前期 | 約8週間（全体の15%まで） | 模試と総復習 |

## 3. 事実と推論の区別

### 事実（制度として定まっていること）
- 試験は選択式（8科目・40問）と択一式（7科目区分・70問、210分）で構成される
- 合否は総得点と科目ごとの得点（足切り）の両方で判定され、基準は年度ごとに補正される
- 問題文・解説は各問の「根拠」欄の条文に基づいて作成した（2026年4月1日時点の法令を前提）

### 推論・仮置き（v0 で置いた前提。検証が必要）
- **試験日の初期値**: 例年8月第4日曜に実施されているため、次回を 2027年8月22日（日）と推定。正式日程は試験案内で確認し、設定画面で直す
- **合格の目安 70%**: 択一式の合格基準は例年おおむね6割強のため、余裕を見た値
- **1日25問 ≒ 30分**: 1問あたりの所要時間は未計測。実利用の学習時間ログで見直す
- **インプット期の配分**: 条文量の多さで重み付けした目安（労基・健保・国年・厚年を厚め）

## 4. 既知の課題（v1 以降）

| 課題 | 内容 | 優先度 |
| --- | --- | --- |
| 問題数が足りない | 1年分の計画を回すには、新問10問/日 × 約190日 ≒ 2,000問規模が必要。現在260問（§5 で拡充中） | 最優先 |
| 内容の確認 | 監修者はいない。§5.2 の自己確認の仕組みで補う。法改正・数値改定は毎年見直す | 高 |
| 選択式対策 | 空欄補充（語群から選ぶ）形式が未対応 | 高 |
| 白書・統計 | 一般常識で出る白書・労働経済の数値が未収録 | 中 |
| 端末間同期 | 記録は端末内のみ。スマホとPCで続きをやるにはログインとサーバー保存が要る | 中 |
| 通知 | 毎日の学習リマインド（PWA のプッシュ通知など） | 低 |

## 5. 問題データの拡充

### 5.1 目標数（推論）
インプット期（約190日）に毎日10問の新問を出すには約1,900問が要る。
科目の重み（`subjects.ts` の `weight`、条文量の目安）で割り振ると次のとおり。

| 科目 | 重み | 目標 | 現在 |
| --- | --- | --- | --- |
| 労働基準法 | 3 | 270 | 32 |
| 労働安全衛生法 | 1 | 90 | 26 |
| 労災保険法 | 2 | 180 | 35 |
| 雇用保険法 | 2 | 180 | 23 |
| 労働保険徴収法 | 1 | 90 | 12 |
| 健康保険法 | 3 | 270 | 38 |
| 国民年金法 | 3 | 270 | 32 |
| 厚生年金保険法 | 3 | 270 | 31 |
| 労働に関する一般常識 | 2 | 180 | 17 |
| 社会保険に関する一般常識 | 2 | 180 | 14 |
| 合計 | | 1,980 | 260 |

現在の量では新問は約26日で出尽くし、その後は復習と苦手問題の前倒しだけになる。
アプリは問題が足りなくても止まらないが、計画どおりの学習量にはならない。

### 5.2 作り方と品質のルール
1. **作問**: 1つの記述に1つの論点。数字・期間・主体（誰が／誰に）を入れ替えた「誤り」の記述を、正しい記述3〜4問に1問の割合で混ぜる（模試で「誤りを1つ選ぶ」問題を作るため）
2. **根拠**: すべての問題に根拠条文（法・施行令・施行規則・通達）を付ける。根拠を示せない問題は入れない
3. **改正の注記**: 施行日が近い改正（例: 雇用保険の週10時間への適用拡大、厚生年金の標準報酬月額の上限引上げ）に関わる問題は、解説に「施行時期に注意」と書く
4. **検査**: `npm run check:questions` を通す（ID の重複、空欄、模試を作れる量か）
5. **自己確認**（監修者がいないため、学習しながら確かめる）
   - 解説の下の根拠リンクから e-Gov 法令検索の条文を開ける（通知・要領は厚生労働省の資料を検索）
   - 「条文で確認した」で確認済み、「誤りを報告」でメモ付きの要修正にできる。問題文の上に「未確認／確認済み／要修正」を表示
   - 「振り返り」タブの「問題の確認状況」から報告内容をコピーし、Claude に渡して問題データを直す
   - 毎年4月の法改正の施行後と試験案内の公表後に、改正に関わる問題を見直して `LAW_AS_OF` を更新する

### 5.3 体制
自分用で公開しないため、監修者は置かず §5.2 の自己確認で運用する（決定）。
問題の下書きは Claude が行い、学習中の確認・報告で誤りをつぶしていく。
公開する方針に変わった場合は、有資格者の監修を必須にする。

## 6. 問題データの追加方法

`src/lib/sharoushi/questions/<科目ID>.ts` に追記する（科目IDは `subjects.ts` を参照）。

```ts
["kenpo-26", true, "問題文", "解説", "健保法○条"],
```

- ID は学習記録のキーなので、一度公開したら変えない
- 模試を作るには、各科目区分に「誤りの記述」が2つ以上、「正しい記述」が8つ以上必要
- 法改正で内容を直したら `questions/index.ts` の `LAW_AS_OF` も更新する
- 追記したら `npm run check:questions` を実行する
