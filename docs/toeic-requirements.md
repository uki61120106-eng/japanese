# TOEIC トレーナー 要件定義書

かなフラッシュと同じリポジトリに、別ページ（`/toeic`）として追加した学習アプリの要件。

## 1. 目的とスコープ

| 項目 | 内容 |
| --- | --- |
| 何のアプリか | TOEIC L&R の Part 5・Part 7 を解いて力をつけるための学習アプリ |
| 想定ユーザー | 作者本人のみ。700点前後を目標とする学習者 |
| 位置づけ | 個人利用。ログインなし、サーバー保存なし、通信なしで完結する |
| 既存アプリとの関係 | かなフラッシュ（`/`）はそのまま残し、相互にリンクを置く |

### 1.1 なぜ Part 5 と Part 7 か

- Part 5 は1問が短く、文法項目ごとに弱点を切り分けやすい。スキマ時間に回せる
- Part 7 はリーディング100問中54問を占め、配点上の比重が大きい
- リスニング（Part 1〜4）は音声が要るため、今回は対象外とした（第6章）

## 2. 収録コンテンツ

| 項目 | 内容 |
| --- | --- |
| Part 5 | 120問。文法・語彙の10カテゴリ × 各12問 |
| Part 7 | 10文書・34問。シングルパッセージのみ |
| 出所 | すべて本リポジトリ用の書き下ろし。公式問題集・市販教材からの転載はしない |
| 難易度 | 600〜730点帯を想定 |
| 付属情報 | 全問に日本語の解説。Part 5 は和訳、Part 7 は本文の和訳を付ける |

### 2.1 Part 5 のカテゴリ

品詞 / 動詞の形 / 態 / 前置詞 / 接続詞 / 代名詞 / 関係詞 / 比較 / 準動詞 / 語彙

### 2.2 Part 7 の文書種別と設問タイプ

- 文書: Eメール、お知らせ、広告、記事、チャット、帳票
- 設問: 主旨、詳細、NOT 問題、推測、意図問題（チャット）、同義語

### 2.3 データの品質保証

手書きのデータなので、`npm run check:toeic` で以下を機械的に検査する。

- id の重複
- 空所（`____`）が1問につき1個であること
- 選択肢が4つで、重複がないこと
- 正解番号が 0〜3 の範囲であること
- 解説・和訳が空でないこと
- 正解の位置（A〜D）の分布。偏っていると位置で当てられてしまうため、
  Part 5 はカテゴリごとに 3/3/3/3 に均してある

## 3. 学習の仕組み

### 3.1 出題の3メニュー

| メニュー | 出題内容 |
| --- | --- |
| 復習 | 復習期限が来ている問題だけを、期限の古い順に最大20問 |
| Part 5 | 選んだカテゴリから 10 / 20 / 30 問 |
| Part 7 | 1 / 2 / 3 文書（1文書あたり設問3〜4問） |

Part 5 と Part 7 では、復習期限が来ている問題 → 未学習の問題 → それ以外、の順に選ぶ。

### 3.2 間隔反復

箱（0〜5）で習熟度を持ち、正解したら1つ上げ、不正解なら0に戻す。

| 箱 | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| 次の出題まで | 当日中 | 1日 | 3日 | 7日 | 14日 | 30日 |

### 3.3 解答時間

1問ごとに経過秒数を表示する。目安を超えると表示色が変わる。

| パート | 目安 |
| --- | --- |
| Part 5 | 20秒 |
| Part 7 | 60秒 |

これは一般的な学習目標としての目安であり、公式のスコア換算ではない。

## 4. 画面

### 4.1 ホーム（`/toeic`）
- 集計タイル: 今日の復習 / 累計正答率 / 学習した問題数 / 連続学習日数
- 学習メニューの切替（復習 / Part 5 / Part 7）
- Part 5: カテゴリの複数選択、問題数の選択
- Part 7: 文書数の選択
- スタートボタン（条件を満たさないときは無効化）
- 700点をねらうときの目安（目安である旨を明記する）
- かなフラッシュへのリンク、学習記録の削除

### 4.2 出題
- 進捗（`3 / 10 問`）、経過秒数、やめる
- Part 7 のときは本文（たたむことができる）
- 設問と4択。選ぶと即座に正誤判定
- 判定後: 正誤、解説、和訳（Part 5）／本文の和訳の表示切替（Part 7）
- 「次の問題へ」／最後の問題では「結果を見る」
- 「やめる」で中断した場合、解答済みの分は記録に残す

### 4.3 結果
- 正答率、正解数・不正解数、1問あたりの平均秒数
- カテゴリ別の正誤（Part 5 のみ）
- まちがえた問題の一覧
- 「まちがえた N 問をもう一度」「ホームへもどる」

## 5. 技術要件

| 項目 | 内容 |
| --- | --- |
| フレームワーク | Next.js（App Router）+ TypeScript。既存アプリと共用 |
| UI | shadcn/ui + Tailwind CSS v4。英文のみ別フォント（`.font-english`） |
| 通信 | なし。問題データはアプリに同梱する |
| 保存 | ブラウザの localStorage（キー `toeic-trainer:log:v1`）のみ |
| 保存できない環境 | プライベートモード等で例外が出ても、その回の学習は続けられる |
| 対応 | 最新のモダンブラウザ。スマートフォン幅を優先 |

### 5.1 保存とサーバー描画の整合

localStorage はサーバー描画時に読めない。`useSyncExternalStore` の
サーバー用スナップショットとして空のログを返し、ハイドレーション後に
実データへ差し替える。読み込みが済むまで、集計タイルの数値は `—` を出す。

## 6. 今回は作らないもの

将来の検討事項として記録しておく。

- リスニング（Part 1〜4）。音声の用意が必要で、読み上げ機能で代用すると
  実際の試験音声とは音質が異なる
- Part 6（長文穴埋め）、Part 7 のダブル・トリプルパッセージ
- 本番形式の通し模試（2時間200問）と、スコア換算
- 学習記録の端末間の引き継ぎ（書き出し・読み込み）
- 単語帳（フラッシュカード形式の語彙学習）
- 間違いの傾向から出題カテゴリを自動で重みづけする機能
