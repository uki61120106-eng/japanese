# TOEIC トレーナー 要件定義書

かなフラッシュと同じリポジトリに、別ページ（`/toeic`）として追加した学習アプリの要件。

## 1. 目的とスコープ

| 項目 | 内容 |
| --- | --- |
| 何のアプリか | TOEIC L&R の語彙・Part 5・Part 7 を解いて力をつけるための学習アプリ |
| 想定ユーザー | 作者本人のみ。800点を目標とする学習者 |
| 位置づけ | 個人利用。ログインなし、サーバー保存なし、通信なしで完結する |
| 既存アプリとの関係 | かなフラッシュ（`/`）はそのまま残し、相互にリンクを置く |

### 1.1 目標スコアの変遷

当初は700点を目標に Part 5・Part 7 の基礎（600〜730点帯）だけを収録した。
その後、目標を800点に引き上げたため、次の2つを追加した。

- フレーズカード（頻出コロケーション・定型表現）
- Part 5・Part 7 の応用（730〜860点帯）。Part 7 にはマルチプルパッセージを含む

基礎の問題は取り崩さずに残してある。土台の確認と、間隔反復の材料として使うため。

### 1.2 なぜこの3本立てか

- **フレーズ** 800点帯で落とすのは、文法よりも語彙と語法。単語1語ではなく
  「どの語とどの語が結びつくか」で覚えるほうが、Part 5 の語彙問題と
  Part 7 の言い換えの両方に効く
- **Part 5** 1問が短く、文法項目ごとに弱点を切り分けやすい。スキマ時間に回せる
- **Part 7** リーディング100問中54問を占め、配点上の比重が大きい
- リスニング（Part 1〜4）は音声が要るため、今回も対象外とした（第7章）

## 2. 収録コンテンツ

| 区分 | 分量 | 難易度 |
| --- | --- | --- |
| フレーズカード | 150枚（6分類 × 各25枚） | 730〜860点帯 |
| Part 5 基礎 | 120問（10カテゴリ × 各12問） | 600〜730点帯 |
| Part 5 応用 | 60問（10カテゴリ × 各6問） | 730〜860点帯 |
| Part 7 基礎 | 10セット34問（すべて単一文書） | 600〜730点帯 |
| Part 7 応用 | 5セット24問（うち2セットは2文書） | 730〜860点帯 |

合計388問。出所はすべて本リポジトリ用の書き下ろしで、公式問題集・市販教材からの
転載はしない。

### 2.1 フレーズカードの分類

| 分類 | 例 |
| --- | --- |
| 動詞＋名詞 | meet a deadline, waive a fee |
| 動詞＋前置詞 | comply with, dispose of |
| 形容詞＋前置詞 | be eligible for, be subject to |
| 前置詞句 | in accordance with, in lieu of |
| ビジネス定型 | Please be advised that, effective immediately |
| 名詞句 | purchase order, minutes of the meeting |

1枚につき、フレーズ・日本語の意味・例文・例文の和訳を持つ。紛らわしい語との
違いがある場合は補足を付ける（result in と result from など）。

### 2.2 Part 5 のカテゴリ

品詞 / 動詞の形 / 態 / 前置詞 / 接続詞 / 代名詞 / 関係詞 / 比較 / 準動詞 / 語彙

応用では、基礎で扱わない構文を意図的に入れている。仮定法（過去完了・現在）、
if の省略による倒置、否定語句の文頭倒置、譲歩の as、複合関係詞、
no sooner ... than、意味の近い語の使い分け（corroborate / collaborate など）。

### 2.3 Part 7 の文書種別と設問タイプ

- 文書: Eメール、お知らせ、広告、記事、チャット、帳票、日程表、レビュー
- 設問: 主旨、詳細、NOT 問題、推測、意図問題、同義語
- 応用のみ: 2通の文書を突き合わせないと解けない設問（クロスリファレンス）、
  本文に直接書かれていない数値の比較

### 2.4 データの品質保証

手書きのデータなので、`npm run check:toeic` で以下を機械的に検査する。

- id の重複（学習ログのキーになるため、コンテンツ全体で一意であること）
- 空所（`____`）が1問につき1個であること
- 選択肢が4つで、重複がないこと
- 正解番号が 0〜3 の範囲であること
- 解説・和訳・例文が空でないこと
- 同じフレーズが2枚ないこと
- Part 7 の各セットに文書が1通以上あり、設問が2〜5問であること
- 正解の位置（A〜D）の分布

正解の位置が偏ると、内容を読まずに位置で当てられてしまう。基礎の Part 5 は
カテゴリごとに 3/3/3/3、応用は全体で 15/15/15/15、Part 7 は全体で
15/15/14/14 に均してある。

## 3. 学習の仕組み

### 3.1 出題の4メニュー

| メニュー | 出題内容 |
| --- | --- |
| 復習 | 復習期限が来ている問題だけを、期限の古い順に最大20問 |
| フレーズ | 選んだ分類から 20 / 30 / 50 枚 |
| Part 5 | 選んだ難易度とカテゴリから 10 / 20 / 30 問 |
| Part 7 | 選んだ難易度から 1 / 2 / 3 セット（1セットあたり設問3〜5問） |

復習以外のメニューでも、復習期限が来ている問題 → 未学習の問題 → それ以外、
の順に選ぶ。復習メニューは区分をまたいで期限順に集める。

### 3.2 間隔反復

箱（0〜5）で習熟度を持ち、正解したら1つ上げ、不正解なら0に戻す。
フレーズカードは「おぼえてた」を正解、「あやふや」を不正解として扱う。

| 箱 | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| 次の出題まで | 当日中 | 1日 | 3日 | 7日 | 14日 | 30日 |

### 3.3 解答時間

1問ごとに経過秒数を表示する。目安を超えると表示色が変わる。

| 区分 | 目安 |
| --- | --- |
| フレーズ | 15秒 |
| Part 5 | 20秒 |
| Part 7 | 60秒 |

これは一般的な学習目標としての目安であり、公式のスコア換算ではない。

## 4. 画面

### 4.1 ホーム（`/toeic`）
- 集計タイル: 今日の復習 / 累計正答率 / 学習した問題数 / 連続学習日数
- 学習メニューの切替（復習 / フレーズ / Part 5 / Part 7）
- フレーズ: 分類の複数選択、枚数の選択
- Part 5: 難易度の複数選択、カテゴリの複数選択、問題数の選択
- Part 7: 難易度の複数選択、セット数の選択
- スタートボタン（条件を満たさないときは無効化）
- 800点をねらうときの目安（目安である旨を明記する）
- かなフラッシュへのリンク、学習記録の削除

### 4.2 出題
- 進捗（`3 / 20 問`）、経過秒数、やめる
- フレーズ: 表にフレーズのみ。「意味を見る」で意味・例文・補足を出し、
  「あやふや」「おぼえてた」の2択でそのまま次へ進む
- Part 5 / Part 7: 設問と4択。選ぶと即座に正誤判定し、解説を出す。
  「次の問題へ」で進む
- Part 7 は文書を上に表示する。複数文書のセットは「文書1」「文書2」として
  縦に並べ、たたむこともできる
- 答え合わせのあとに和訳を出せる（Part 5 は自動、Part 7 は表示切替）
- 「やめる」で中断した場合、解答済みの分は記録に残す

### 4.3 結果
- 正答率、正解数・不正解数、1問あたりの平均秒数
- カテゴリ別の正誤（Part 5 のみ）
- 見直したい問題の一覧（フレーズはフレーズと意味、4択は問題文と正解）
- 「まちがえた N 問をもう一度」「ホームへもどる」

## 5. 技術要件

| 項目 | 内容 |
| --- | --- |
| フレームワーク | Next.js（App Router）+ TypeScript。既存アプリと共用 |
| UI | shadcn/ui + Tailwind CSS v4。英文のみ別フォント（`.font-english`） |
| 通信 | なし。問題データはアプリに同梱する |
| 保存 | ブラウザの localStorage（キー `toeic-trainer:log:v1`）のみ |
| 保存できない環境 | プライベートモード等で例外が出ても、その回の学習は続けられる |
| 対応 | 最新のモダンブラウザ。スマートフォン幅を優先 |

### 5.1 保存とサーバー描画の整合

localStorage はサーバー描画時に読めない。`useSyncExternalStore` の
サーバー用スナップショットとして空のログを返し、ハイドレーション後に
実データへ差し替える。読み込みが済むまで、集計タイルの数値は `—` を出す。

### 5.2 データの持ち方

難易度帯でファイルを分け、`src/lib/toeic/content.ts` でまとめて扱う。

| ファイル | 中身 |
| --- | --- |
| `phrases.ts` | フレーズカード150枚 |
| `part5-questions.ts` | Part 5 基礎120問 |
| `part5-advanced.ts` | Part 5 応用60問 |
| `part7-sets.ts` | Part 7 基礎10セット |
| `part7-advanced.ts` | Part 7 応用5セット |

Part 7 の1セットは文書の配列を持つ。1通ならシングルパッセージ、
2通以上ならマルチプルパッセージとして同じ型で扱う。

## 6. 学習記録が消える条件

利用者が把握しておくべき制約として明記しておく。

- ブラウザのサイトデータを削除すると消える
- 別の端末・別のブラウザには引き継がれない
- ポート番号が変わると別サイト扱いになり、記録も別になる
  （`localhost:3000` と `localhost:3001` は別物）

## 7. 今回は作らないもの

将来の検討事項として記録しておく。

- リスニング（Part 1〜4）。音声の用意が必要で、読み上げ機能で代用すると
  実際の試験音声とは音質が異なる
- Part 6（長文穴埋め）、Part 7 のトリプルパッセージ
- 本番形式の通し模試（2時間200問）と、スコア換算
- 学習記録の端末間の引き継ぎ（書き出し・読み込み）
- 間違いの傾向から出題カテゴリを自動で重みづけする機能
- フレーズを4択形式でも出題する（現状はカード形式のみ）
