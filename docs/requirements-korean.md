# ハングルフラッシュ 要件定義書

韓国語版デモ（v0）の要件。既存の「かなフラッシュ」と同じリポジトリに、
別ルート（`/korean`）のアプリとして追加した。

## 1. 目的とスコープ

| 項目 | 内容 |
| --- | --- |
| 何のアプリか | 韓国語の基本のあいさつと日常の単語を覚えるための学習アプリ |
| 想定ユーザー | 韓国語をこれから始める日本語話者（文字も読めない段階から） |
| 今回の位置づけ | デモアプリ。通信なし・ログインなしで単体で動くこと |
| かなフラッシュとの関係 | UI 部品・学習ロジック・1枚 HTML 化の仕組みを共有し、データと画面は別に持つ |

## 2. 収録する内容

| 項目 | 決定内容 |
| --- | --- |
| 収録数 | 96語（9分野） |
| 分野 | あいさつ12 / お礼と返事11 / 自己紹介10 / 数字15 / 食べもの10 / 買いもの10 / 移動・場所11 / 毎日のことば10 / 困ったとき7 |
| 1語の情報 | ハングル、カタカナ読み、ローマ字（文化観光部2000年式）、日本語の意味、使う場面のメモ |
| メモの使い方 | 敬体とくだけた言い方の違い（例: 안녕하세요 / 안녕）、使い分け（例: 안녕히 계세요 / 안녕히 가세요）を短く添える |
| 数字 | 漢数詞（일〜십）と固有数詞（하나〜다섯）の両方 |

## 3. 学習の仕組み

| 項目 | 決定内容 |
| --- | --- |
| 練習の形 | ①カード（表 → タップ → 裏）、②4択クイズ の2種類 |
| 出題の向き | 「韓国語 → 日本語」「日本語 → 韓国語」を切り替え可能 |
| カードの裏 | 答え＋カタカナ読み＋ローマ字＋使う場面のメモ |
| クイズの選択肢 | 同じ分野の語を優先してダミーに使う。意味が重なる語（감사합니다 と 고맙습니다 など）は正解が2つになるため候補から外す |
| クイズの回答後 | 正解・不正解を色で示し、ハングル・読み・意味・メモを表示してから次へ進む |
| 出題範囲の指定 | 分野を複数選択（「すべて選ぶ / すべて外す」） |
| 出題順 | シャッフル ON / OFF を切り替え可能 |
| セット終了時 | 結果画面（正答率・語数・おさらいする語の一覧） |
| 復習 | 「まちがえた N 語をもう一回」「おなじ N 語をもう一回」 |

## 4. 画面

### 4.1 ホーム（`/korean`）
- 練習の形（カード / 4択クイズ）の切替タブ
- 出題の向き（韓国語 → 日本語 / 日本語 → 韓国語）の切替タブ
- 分野の選択（複数選択、分野ごとの語数を表示）
- シャッフルの ON / OFF
- 選択語数の表示、スタートボタン
- 分野が0個のときはスタートを無効化

### 4.2 練習（カード）
- 進捗表示（`3 / 20 語`）とプログレスバー
- カード（タップで表裏がめくれる。3Dフリップ）
- 「わすれてた」「おぼえてた」ボタン
- 「やめる」でホームへ戻る

### 4.3 練習（4択クイズ）
- 進捗表示（`3 / 20 問`）とプログレスバー
- 問題カード（分野名つき）と4つの選択肢
- 回答後に正解・不正解と解説（読み・意味・メモ）を表示し、「つぎの問題」で進む
- 「やめる」でホームへ戻る

### 4.4 結果
- 正答率（%）、おぼえてた（せいかい）語数 / わすれてた（まちがい）語数
- おさらいする語の一覧（ハングル・読み・意味）
- 「まちがえた N 語をもう一回」「おなじ N 語をもう一回」「ホームへもどる」

## 5. デザイン方針

- かなフラッシュと同じ「ポップでカラフル」の方針。分野ごとに色を割り当て、
  チップ・カード表面・進捗バーで色を共有する
- アプリの主色は青〜紫系にして、かなフラッシュ（赤〜桃系）と見分けられるようにする
- スマートフォン幅（〜420px）を基準にレイアウトする
- OS のダークモード設定に追従する（切替 UI は持たない）
- あいさつ文は「안녕히 계세요」のように長いため、文字数に応じて文字サイズを変える

## 6. 技術要件

| 項目 | 内容 |
| --- | --- |
| フレームワーク | Next.js（App Router）+ TypeScript |
| UI | shadcn/ui + Tailwind CSS v4（かなフラッシュと共通の部品を利用） |
| 通信 | なし。単語データはアプリに同梱する |
| 状態 | React の state のみ。保存・永続化はしない |
| フォント | ハングルは M PLUS Rounded 1c に字形が無いため、`/korean` でのみ Noto Sans KR を追加で読み込む。読み込めない環境は端末内蔵のハングルフォントにフォールバック |
| 共有用の配布 | `npm run build:demo:korean` で1枚の HTML（`dist-demo/korean.html`）に束ねる |
| 対応 | 最新のモダンブラウザ（スマホ幅を優先） |

## 7. 今回は作らないもの

- 語数の拡張（旅行・ビジネスなど場面別のセット追加）
