# RM 計算機 要件メモ

v0 の要件。依頼は「RM（レペティション・マキシマム／最大挙上重量）の計算アプリを作って」の1文。
依頼文に書かれていない点は、下の「判断の理由」に残す。

## 機能

| 項目 | 内容 |
| --- | --- |
| 置き場所 | 既存の Next.js アプリに `/rm` として同居（他の画面・データとは独立） |
| 入力 | 重量（kg）と回数（1〜20回） |
| 出力 | 推定 1RM、7つの推定式ごとの値、RM 換算表（1〜20RM）、目的別（筋力・筋肥大・筋持久力）の重量 |
| 丸め | 換算表と目的別はプレートの刻み（0.5 / 1.25 / 2.5 / 5 kg）に合わせる |
| 保存 | 前回の入力だけを端末のブラウザ（localStorage）に保存。通信なし |
| スマホ | ホーム画面に追加できる（PWA）。一度開けば通信なしで起動。スマホのブラウザで開いたときだけ追加の案内を出す（閉じたら再表示しない） |

## 推定式（w = 重量, r = 回数）

| 式 | 1RM |
| --- | --- |
| Epley | w × (1 + r/30) |
| Brzycki | w × 36 / (37 − r) |
| Lander | 100w / (101.3 − 2.67123r) |
| Lombardi | w × r^0.1 |
| Mayhew | 100w / (52.2 + 41.9e^(−0.055r)) |
| O'Conner | w × (1 + 0.025r) |
| Wathan | 100w / (48.8 + 53.8e^(−0.075r)) |

初期値は7式の平均。1回のときはどの式でも入力した重量がそのまま 1RM。

## 判断の理由

- **式の既定を平均にした**：どの式が最も正しいかは種目や個人で変わり、一つに決める根拠がないため。個別の式も選べるようにした。
- **回数の上限を20回**：Brzycki 式は37回で発散し、どの式も高回数ほどずれが大きい。10回を超えたら注意を表示する。
- **目的別の割合**：NSCA の一般的な区分（筋力 85%以上、筋肥大 67〜85%、筋持久力 67%以下）に沿った目安とした。
- **単位は kg のみ**：国内の利用を想定。lb が必要なら後から追加できる。
