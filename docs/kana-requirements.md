# かなフラッシュ 要件定義書

デモ版（v0）の要件。ヒアリング（一問一答）の結果をそのまま記録したもの。

## 1. 目的とスコープ

| 項目 | 内容 |
| --- | --- |
| 何のアプリか | 日本語（かな文字）を覚えるための学習アプリ |
| 想定ユーザー | 日本語の文字がまだ読めない初心者 |
| 今回の位置づけ | デモアプリ。通信なし・ログインなしで単体で動くこと |

## 2. 学習の仕組み

| 項目 | 決定内容 |
| --- | --- |
| 練習の形 | フラッシュカード（表 → タップ → 裏） |
| カードの表 | 大きな文字（例: `あ`） |
| カードの裏 | ローマ字（`a`）＋ 例単語（`あめ` / `ame` / 雨） |
| 収録範囲 | ひらがな46字 ＋ カタカナ46字 ＝ 92枚 |
| 出題範囲の指定 | ひらがな / カタカナ の切替、行（あ行〜ん）を選択 |
| 出題順 | シャッフル ON / OFF を切り替え可能 |
| 1枚ごとの操作 | 「おぼえてた」「わすれてた」の2ボタンで次のカードへ |
| セット終了時 | 結果画面（正答率・枚数・忘れた文字の一覧） |
| 復習 | 「まちがえたカードだけもう一回」「同じセットをもう一回」 |

## 3. 画面

### 3.1 ホーム
- ひらがな / カタカナ の切替タブ
- 行の選択（複数選択、「すべて選ぶ / すべて外す」）
- シャッフルの ON / OFF
- 選択枚数の表示、スタートボタン
- 行が0個のときはスタートを無効化

### 3.2 練習
- 進捗表示（`3 / 20 まい`）とプログレスバー
- カード（タップで表裏がめくれる。3Dフリップ）
- 「わすれてた」「おぼえてた」ボタン
- 「やめる」でホームへ戻る

### 3.3 結果
- 正答率（%）、おぼえてた枚数 / わすれてた枚数
- わすれてた文字の一覧
- 「まちがえた N まいをもう一回」「おなじ N まいをもう一回」「ホームへもどる」

## 4. デザイン方針

- ポップでカラフル。行ごとに色を割り当て、カード表面・行チップ・進捗バーで色を共有する
- 角丸を大きめに取り、丸ゴシック（M PLUS Rounded 1c）で親しみやすい印象にする
- スマートフォン幅（〜420px）を基準にレイアウトする
- OS のダークモード設定に追従する（切替 UI は持たない）

## 5. 技術要件

| 項目 | 内容 |
| --- | --- |
| フレームワーク | Next.js（App Router）+ TypeScript |
| UI | shadcn/ui + Tailwind CSS v4 |
| 通信 | なし。カナのデータはアプリに同梱する |
| 状態 | React の state のみ。保存・永続化はしない |
| 対応 | 最新のモダンブラウザ（スマホ幅を優先） |

## 6. 今回は作らないもの

将来の検討事項として記録しておく。

- ログイン、サーバー保存、学習履歴の永続化
- 音声読み上げ、書き順アニメーション
- 濁点・半濁点・拗音（が・ぱ・きゃ など）、漢字、単語帳
- 4択クイズ／入力式など、フラッシュカード以外の出題形式
- 苦手な文字を優先して出題する間隔反復アルゴリズム
