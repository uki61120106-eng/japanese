# おうち筋トレ20 要件定義書

v0 の要件。依頼は「家でやれる筋トレアプリ。道具を使わないメニュー。毎日20分。体重1年で3キロ減目標」の1文。
依頼文に書かれていない点は、下の「6. 依頼文にない部分の決め方」に判断の理由と一緒に残す。

## 1. 目的とスコープ

| 項目 | 内容 |
| --- | --- |
| 何のアプリか | 道具を使わない自宅トレーニングを毎日20分続けるためのアプリ |
| 目標 | 1年で体重 −3kg |
| 置き場所 | 既存の Next.js アプリに `/workout` として同居（かなフラッシュとは画面・データとも独立） |
| 通信 | なし。ログインなし。記録は端末のブラウザ（localStorage）に保存 |

## 2. トレーニングの組み立て

1回 = 20分（1200秒）ちょうど。

| 区間 | 長さ | 中身 |
| --- | --- | --- |
| ウォームアップ | 45秒 × 4種目 = 3分 | 足踏み・肩まわし・股関節まわし・体ひねり |
| メイン | 60秒 × 7種目 × 2周 = 14分 | 60秒の中を運動と休憩に分ける（比率はレベルで変わる） |
| クールダウン | 45秒 × 4種目 = 3分 | 太もも前・もも裏・お尻・胸のストレッチ |

| レベル | 運動 / 休憩 |
| --- | --- |
| 初級 | 30秒 / 30秒 |
| 中級 | 40秒 / 20秒 |
| 上級 | 45秒 / 15秒 |

曜日ごとにメイン7種目を変える（同じ部位を2日続けて追い込まない）。

| 曜日 | テーマ |
| --- | --- |
| 月 | 下半身 |
| 火 | 上半身と体幹 |
| 水 | 全身の有酸素 |
| 木 | お尻と脚 |
| 金 | 体幹 |
| 土 | 全身ミックス |
| 日 | 回復の日（軽い動き） |

## 3. 画面

### 3.1 今日
- 今日のテーマ、メイン7種目、消費カロリーの目安
- レベル（初級 / 中級 / 上級）、静音モード、音声ガイドの切り替え
- 「20分スタート」
- 今週の達成状況と連続日数

### 3.2 トレーニング中
- 5秒の準備のあと自動で進む。区間の種類（ウォームアップ / 運動 / 休憩 / クールダウン）ごとに色を変える
- 残り秒数の円、種目名・動きのポイント・きついときの軽い版
- 休憩中は「次の種目」を表示
- 全体の経過 / 残り時間、一時停止・前へ・次へ・やめる
- 合図：区間の切り替えと残り3秒で音、種目名の読み上げ、左右交代の種目は折り返しで「反対側へ」
- 画面が暗くならないようにする（Wake Lock。非対応端末では何もしない）

### 3.3 終了
- 消費カロリー（推定）と、1日の目標に対する割合、連続日数
- 今日の体重の入力

### 3.4 記録
- 月カレンダー（やりきった日 / 途中まで の2段階）
- その月の達成日数・運動時間・消費カロリー
- 最近10回の一覧

### 3.5 目標
- 初回は今の体重を入れて目標を作る（1年後 = 開始 −3kg）
- 開始 / いま / 1年後の目標、達成率、目標ラインとの差
- 1年分の体重グラフ（目標の直線と記録を重ねる）
- 目標の計算の内訳と、直近4週の運動による消費の平均
- 体重記録の一覧と削除、目標の作り直し

## 4. 計算

| 項目 | 式・値 | 種別 |
| --- | --- | --- |
| 体脂肪1kgのエネルギー | 7,200 kcal | 一般に使われる目安 |
| 3kg分 | 21,600 kcal | 上から計算 |
| 1日あたり必要な上乗せ | 21,600 ÷ 365 ≒ 59 kcal | 上から計算 |
| 消費カロリー | (MET − 1) × 体重kg × 時間h × 1.05 | 推定。安静時の分（1 MET）は差し引く |
| 種目の MET | 2.3〜8.0 | Compendium of Physical Activities の自重トレーニング区分を目安にした概算 |
| 目標ライン | 開始日から1年後まで直線 | — |
| 記録する条件 | 60秒以上動いたとき。全体の8割以上やって最後まで進んだら「やりきった」 | — |

体重65kgでの1回あたりの推定（静音モード ON）: 初級 平均約40kcal / 中級 約47kcal / 上級 約50kcal。
運動だけでは1日59kcalに少し届かない見込みのため、目標画面で食事側の調整（1日50kcal前後）を案内する。

## 4.5 スマホ対応（PWA）

| 項目 | 内容 |
| --- | --- |
| ホーム画面に追加 | Web App Manifest（名前「おうち筋トレ20」/ 短い名前「筋トレ20」、起動 URL・範囲は `/workout`、縦向き、単独表示） |
| オフライン | Service Worker が画面と JS / CSS / アイコン / フォントを保存。画面は通信優先、つながらなければ保存分を表示 |
| 案内 | スマホのブラウザで開いたときだけ「今日」タブに表示。Android はボタン、iPhone は共有メニューの手順。閉じたら出さない |
| 画面 | ノッチ・ホームバーを避ける余白（safe-area）、ダブルタップでの拡大を止める |
| 制約 | 公開には https が必要。iPhone は Safari とホーム画面版で保存場所が別。1枚の HTML 版はホーム画面に追加できない |

## 5. 技術要件

| 項目 | 内容 |
| --- | --- |
| フレームワーク | Next.js（App Router）+ TypeScript。既存アプリと同じ構成 |
| UI | shadcn/ui + Tailwind CSS v4。差し色はオレンジ（`.theme-workout`） |
| 保存 | localStorage（キー `ie-kintore:v1`）。読めない端末でも開いている間は動く |
| 共有 | `npm run build:workout` で1枚の HTML（`dist-demo/workout.html`） |

## 6. 依頼文にない部分の決め方

| 論点 | 決めたこと | 理由 |
| --- | --- | --- |
| 毎日やると疲れが溜まる | 日曜を「回復の日」にして軽い種目にする | 「毎日20分」を守りつつ、同じ部位を連日追い込まない |
| 集合住宅での足音 | 静音モードを用意し、初期値を ON | 自宅前提。跳ぶ種目は跳ばない代わりの種目に差し替える |
| 運動経験 | 初期値は初級 | 続けることが目標達成の前提 |
| 画面を見続けられない | 音声ガイドを初期値 ON | 床で行う種目が多い |
| 体重が未入力 | 消費カロリーの推定に 60kg を仮置き | 入力後は最新の体重を使う |

## 7. 追加機能（v0.2）

### 7.1 毎日のリマインダー（「設定」タブ）

サーバーを持たない方針を変えずに、確実に届く仕組みを優先した。

| 仕組み | 内容 | 届く条件 |
| --- | --- | --- |
| カレンダーに登録（おすすめ） | 「毎日 指定時刻から20分」の予定（通知つき）を .ics ファイルで作り、スマホのカレンダーに入れる | アプリを閉じていても届く（カレンダーアプリが通知する） |
| アプリの通知 | 指定時刻を過ぎて今日まだなら、1日1回だけ通知 | アプリを開いている間（裏に回していても）だけ |
| 「今日」タブの表示 | 時刻を過ぎて今日まだなら、スタートボタンの上に表示 | アプリを開いたとき |

- 初期値は 19:00。予定の UID は固定にし、時刻を変えて登録し直したときに上書きされやすくした
- 閉じていても毎日決まった時刻に届くアプリの通知（Web Push）は、送信用のサーバーが必要なため今回は作らない

### 7.2 食事の工夫（「今日」タブ）

運動だけでは1日約59kcalに少し届かない見込み（4章）のため、減らした分をワンタップで記録する。

| 工夫 | 目安 | 想定 |
| --- | --- | --- |
| 間食を1回やめた | 150kcal | お菓子1回分 |
| 甘い飲み物をお茶・水にした | 140kcal | 清涼飲料 350ml |
| ご飯を小盛りにした | 80kcal | 150g → 100g |
| 揚げ物を焼き・蒸しにした | 100kcal | おかず1品 |
| お酒を1杯減らした | 140kcal | ビール 350ml |
| 夜食をやめた | 200kcal | 軽食1回分 |

- 「今日の運動 + 食事」を1日の目標（約59kcal）と比べて表示する
- 「目標」タブの計算に、直近4週の食事の工夫の平均を加える
- kcal は代表的な量で見積もった目安であり、実測ではない

### 7.3 種目の動きの図解

- 35種目すべてに、棒人間が2〜5つのポーズを行き来するアニメーションを付けた（通信なし・SVG）
- トレーニング中は種目カードの左に大きく、「今日」のメニュー一覧には止めた図を小さく出す
- 手前の手足は区間の色、奥の手足は薄い灰色で描き分ける
- 端末で「視差効果を減らす（動きを減らす）」が有効なときは、止めた図にする

### 7.4 記録のバックアップ（「設定」タブ）

- 書き出し：ファイルに保存、またはコピー（メモ帳やメールに貼って保管）
- 読み込み：ファイルを選ぶ、または貼り付け。中身を確かめてから「いまの記録を置き換える」確認を出す
- 形式は JSON（`{"app":"ouchi-kintore-20","exportedAt":…,"data":…}`）。形がおかしいものは読み込まない

## 8. 今回は作らないもの

- ログイン、サーバー保存、端末をまたいだ記録の自動同期（バックアップで手動で移す）
- アプリを閉じていても届く通知（Web Push。送信サーバーが必要）
- 種目の実写動画
- 食事の細かいカロリー記録（食べたものの入力）
- メニューの自由編集、曜日の入れ替え
