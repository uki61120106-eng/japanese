# 行政書士 1年合格プラン 要件・設計メモ

`/gyosei` で動く、行政書士試験の学習アプリ（v0）。

## 1. 目的

| 項目 | 内容 |
| --- | --- |
| 目的 | 1日30分・約1年の学習で行政書士試験の合格基準に到達する |
| 想定ユーザー | 働きながら受験する社会人（初学者〜） |
| 位置づけ | 通信・ログインなしで単体で動く。記録は端末のブラウザに保存 |

## 2. 試験の前提（事実）

| 項目 | 内容 |
| --- | --- |
| 試験日 | 例年11月の第2日曜日、13:00〜16:00（180分） |
| 法令等 244点 | 5肢択一40問（4点）・多肢選択3問（8点）・記述式3問（20点） |
| 基礎知識 56点 | 5肢択一14問（4点） |
| 合格基準 | 法令等122点以上・基礎知識24点以上・合計180点以上（すべて満たす） |
| 出題の基準日 | 試験年度の4月1日時点で施行されている法令 |

## 3. 学習の仕組み

- **学習計画**：開始日〜試験日の週数を、配点比で12フェーズに伸縮配分（`src/lib/gyosei/plan.ts`）。
  基礎法学 → 憲法 → 行政法 → 民法 → 商法 → 基礎知識 → 総復習・記述 → 直前期。
- **毎日（約30分）**：要点（5分）→ 新しい一問一答（既定10問）→ 間隔反復の復習（既定上限20問）→ 記述式（該当日）。
- **間隔反復**：ライトナー方式。正解で箱が進み 1→1→3→7→14→30→60日後に再出題。誤答で翌日に戻る。箱4以上を「定着」。
- **理解度チェック**：毎週7日目に、その週の単元から15問（目標80%）。科目・単元別の定着率と正答率、弱点単元、苦手克服演習。
- **模試**：一問一答を組み合わせて5肢択一（正しいもの／誤っているもの）を毎回生成。
  - ミニ模試：15問・30分。300点換算で推移を見る（4週ごと）。
  - 本試験形式：60問・180分・本試験と同じ配点と合格基準。中断・再開可。記述式はキーワードで自己採点。
  - 間違えた肢は翌日の復習に入る。

## 4. 収録コンテンツ

`src/lib/gyosei/content/`。一問一答425問（○と×がほぼ半々）、記述式7問、多肢選択6問、全26単元の要点。
問題の id は学習記録のキーなので、**追加は末尾へ、既存の削除・並べ替えはしない**。

## 5. 個人利用の運用（推奨）

- Vercel にデプロイし、スマホで `/gyosei` を開いて「ホーム画面に追加」する（アイコン・単独画面表示に対応）。
- 毎日はアプリの30分を最優先。新しい問題が尽きた後は、市販の問題集を同じ単元で並行して解く。
- 記録は端末内のみ。30日以上書き出していないとホームにバックアップの案内が出る。

## 6. 既知の制約・今後

- 問題数は1年分の新規出題には足りない（計画上は約2か月で一巡し、以降は復習中心になる）。問題の追加が最優先。
- 問題文・解説は法令改正（2025年行政書士法改正、拘禁刑の導入など）に合わせて毎年4月に見直すこと。
- 文章理解（基礎知識）は未収録。
- 記録は端末ローカルのみ。複数端末で使う場合は設定画面の書き出し・読み込みを使う。
